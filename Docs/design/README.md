# Design — дизайн-соглашения

> Появляется на слое **«Дизайн»** (после Слоя 1 «Схема данных», см.
> [`ROADMAP.md`](../ROADMAP.md)). Здесь будут зафиксированы и согласованы:

- стилистика (палитра, шрифты, настроение, референсы);
- элементы UI по экранам;
- для каждого окна/состояния: возможные действия и переходы;
- горячие клавиши (и их мобильные эквиваленты на будущее);
- состояния и их визуальная индикация (выделение, иконки NPC, ошибки).

До слоя «Дизайн» ничего в `Docs/design/` не добавляется.
