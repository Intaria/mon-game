# 07 — Предметы

> Нормализовано из `test.txt` (раздел «Предметы»).

- Все предметы имеют заранее прописанную цену и покупаются/продаются по одинаковой цене для любого NPC.
- Есть расходные предметы (зелья, ягоды, покеболы, камни улучшения). Каждый эффект настраивается персонально.
- Есть квестовые предметы:
  - используются для триггера событий;
  - нельзя продать.
- Есть прочие предметы (выпадающие после боя с диким покемоном):
  - нужны для продажи или крафта.
