# 06 — NPC

> Нормализовано из `test.txt` (раздел «NPC»).

- Каждому NPC возможно настроить внешность и набор косметических предметов так же, как игроку.
- Каждому NPC можно персонально настроить диапазон взаимодействий:
  - **поговорить** — список реплик прописывается вручную;
  - **сразиться** — флаг для возможного боя прописывается вручную и имеет cooldown на повторный бой;
  - **торговать** — список предметов для торговли настраивается вручную;
  - **квестовое взаимодействие**.
- Для появления некоторых торговых позиций у NPC могут быть прописаны дополнительные условия.
- NPC, готовые к сражению или торговле, подсвечивают отдельной иконкой.
