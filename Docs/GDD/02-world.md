# 02 — Мир

> Нормализовано из `test.txt` (раздел «Мир»).

## Структура мира
- Ручное расположение объектов и ландшафта.
- Основная карта мира бесшовная, но есть переходы в отдельные изолированные зоны (например: пещеры).
- Есть Z-ось (например: летающие платформы).
- Есть непроходимые объекты (невидимые стены).
- Есть ландшафт, требующий для прохождения определённых условий (реки, лава).

## Эффекты
- (Рукотворные зоны) Область погодных эффектов: допустимый диапазон эффектов и интервал изменений настраивается вручную.
- Время суток.

## Располагаемые объекты
- NPC.
- Рукотворные строения (например: здания, дороги, дорожные знаки).
- Элементы флоры (например: растения, камни, деревья).
- Подбираемые предметы.
- (Рукотворные зоны) Область генерации покемонов: виды генерируемых покемонов, их шанс и дополнительные условия, максимальное количество одновременно существующих покемонов настраиваются вручную. В зонах также можно переопределить некоторые дефолтные значения для покемонов (например: базовый оттенок).
- Легендарные покемоны (имеют фиксированное расположение). Для появления могут требоваться дополнительные условия.
- (Рукотворные зоны) Области, в которых может напасть случайный покемон, не сгенерированный в мире (аналог «кустов» из серии Pokémon).
