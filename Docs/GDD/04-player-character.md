# 04 — Персонаж

> Нормализовано из `test.txt` (раздел «Персонаж»).

## Общее
- Есть пол и черты внешности.
- Есть слоты для косметических предметов.
- Есть инвентарь для хранения игровых предметов.
- Есть деньги и прочие валюты.
- Есть 6 слотов для переноса активных покемонов (участвующих в бою). Не участвующие покемоны отправляются в банк (отдельный инвентарь, доступный при взаимодействии с определённым объектом на карте).
- Есть карточка персонажа со статистикой и настраиваемыми плитками отображения.

## Покедекс
- Игроку доступна база знаний по всем существующим покемонам с отдельной индикацией по пойманным и уже увиденным покемонам.

## Внешность
- Список настраиваемых параметров (выбор из доступных вариантов): волосы, глаза, лицо, макияж, тело.

## Косметические слоты (персонаж)
- Список возможных косметических слотов: головной убор, верхняя одежда, нижняя одежда, обувь, спина, перчатки, носки, очки, ремни, шея, поза, способ призыва.
