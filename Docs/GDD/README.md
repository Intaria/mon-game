# GDD — Game Design Document

> Источник: авторское описание проекта (`test.txt`, автор — разработчик).
> Документ нормализован: содержание сохранено, структура разбита по системам.
> Любое изменение смысла здесь — осознанное решение, а не редактирование мелочей.

**Референс:** игры серии Pokémon.
