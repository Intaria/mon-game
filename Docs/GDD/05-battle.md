# 05 — Бой

> Нормализовано из `test.txt` (раздел «Бой»).

## Общие правила
- Бой происходит пошагово, в классическом Pokémon-like режиме.
- Бои могут происходить как с диким покемоном, так и с NPC.
- Переход в бой происходит без отдельного экрана — камера просто смещается и появляются подходящие кнопки.
- У NPC может быть несколько покемонов для боя.
- Участвующего в бою покемона можно переключить на другого не-KO из активных.
- Бой завершается, когда все покемоны одной стороны повержены.
- На одной стороне могут участвовать до двух тренеров одновременно (зависит от вручную выставленных параметров в бою).
- Бой может происходить против нескольких диких покемонов одновременно.
- В бою за один «ход» можно совершить одно действие:
  - использовать атаку текущего покемона;
  - поменять покемона;
  - попытаться сбежать;
  - использовать предмет;
  - пасовать.

## Награды
- При победе над диким покемоном с определённым шансом выпадает предмет (пул выпадаемых предметов зависит от побеждаемых покемонов). За раз может выпасть более одного предмета.
- При победе над NPC-тренером победивший игрок получает фиксированное вознаграждение.
- При победе над другим игроком победных предметов не начисляется.
