# 03 — Покемоны

> Нормализовано из `test.txt` (раздел «Покемоны»).

## Общее
- Фиксированный список покемонов, без процедурной генерации.
- У покемонов есть характеристики.
- У каждого вида есть свой тип. Тип влияет на множитель получаемого урона от атак другого типа.
- У покемона есть изученные способности.
- Есть эволюция покемонов. Критерии настраиваются персонально (уровень, время суток, показатель дружбы, применение предметов, количество применений способности, победа над конкретным покемоном и др.). Диапазон возможных видов для эволюции жёстко прописан. Есть виды с разными вариантами эволюции.
- Shiny-покемонов нет.
- Могут размножаться, при целенаправленном запуске игроком, и при выполнении условий (для каждого покемона есть ограничения на возможного партнёра).
- У покемонов есть свойство **мутаций** (влияют на определённые части модели покемона и его характеристики). Для каждого вида настраивается свой лимит на одновременное количество мутаций и набор допустимых мутаций.
- У покемонов есть свойство **пигментации** (влияет на оттенки и накладываемые на модель текстуры). Пигментация для каждого вида доступна в определённом диапазоне оттенков. Для пигментации есть базовый оттенок (при генерации значение пигментации с большей вероятностью будет ближе к базовому).
- Мутации и пигментации независимы друг от друга и с определённым шансом наследуются при размножении (механизм селекции: накапливающиеся очки вероятности от обоих родителей). При эволюции оба свойства сохраняются без изменений.
- У покемонов есть предпочтения по еде.
- У покемонов есть характер. Не влияет на характеристики. Влияет на анимацию и на некоторых покемонов.
- У покемонов есть гендер (могут быть бесполыми).
- У покемонов есть косметические слоты.
- У покемонов есть параметр **размера**. Размер влияет на множитель размера игровой модели. У каждого вида свой диапазон возможных значений.
- У каждого вида покемонов есть свой базовый шанс на поимку и коэффициент сложности (общая формула поимки зависит от выбранного покебола, здоровья покемона и других эффектов).
- У покемонов может быть альтернативный арт/модель. В рамках механик игры правила их получения прописываются отдельно; основной способ получения — временные события.

### Характеристики покемонов
- Список характеристик:
  - **HP** — влияет на здоровье;
  - **Атака** — множитель для физических атак;
  - **Защита** — уменьшает итоговую физическую атаку;
  - **Спец. атака** — множитель для энергетических атак;
  - **Спец. защита** — срезает итоговую энергетическую атаку;
  - **Скорость** — влияет на то, чей ход будет совершён первым.
- Для каждого вида покемонов есть допустимый диапазон для каждой характеристики и общий пул допустимых очков характеристик (формула зависит от уровня).
- При генерации покемона значения формируются случайным образом в рамках допустимых диапазонов. При повышении уровня характеристики повышаются случайным образом до заполнения максимально допустимых очков характеристик.
- Характеристики можно тренировать, увеличивая значения одних за счёт других.
- На итоговое значение характеристик покемона в бою можно повлиять (за счёт предметов, погодных эффектов, усиливающих или ослабляющих эффектов и прочего).

### Тип покемонов
- Покемон всегда относится минимум к одному типу. Максимальное количество типов для покемона — 2.
- Список типов: нормальный, огненный, водный, растение, электрический, ледяной, земляной, стальной, тёмный, светлый, призрачный, летающий.
- WIP: коэффициенты влияния (super effective / not very effective / no effect).

### Способности
- Максимальное количество одновременно выбранных способностей у покемона — 5.
- Способности можно переучить.
- У каждой атаки есть свой тип (аналогичен типу покемонов). У каждой атаки может быть только один тип.
- У каждой атаки есть вид атаки: физический или энергетический.
- У каждого вида покемонов свой диапазон возможных для изучения навыков.
- У каждой способности свои требования для изучения (например: «совершить атаку Х за всё время N раз», «получить уровень Х», «победить над покемоном У» и т. д.).
- У способностей нет количества возможных применений до отдыха, но есть cooldown.
- Некоторые атаки помимо прямого воздействия могут накладывать побочный эффект (бафф или дебафф себя, союзника или оппонента, воздействие на окружение). За одну атаку может быть несколько побочных эффектов.
- Некоторые атаки применяются на себя.
- В бою 2×2 есть возможность выбрать цель для воздействия.
- У некоторых способностей есть шанс промахнуться.
- Некоторые способности могут иметь отложенный эффект, требовать несколько ходов для применения или требовать ходы на восстановление.
- Некоторые способности могут применяться вне боя.

### Статусы
- На покемона могут быть наложены статусы (например: «паралич», «горение»).
- Некоторые статусы не проходят по завершении боя и остаются на покемоне до исцеления в медицинском центре или применения определённого предмета.

## Легендарные покемоны
- В игре существуют легендарные покемоны (единственные в своём виде).
- Для определённых режимов турниров и битв с NPC действуют ограничения на количество легендарных покемонов в команде.
- Нельзя получить с помощью размножения.
- Не могут заспавниться в мире случайно.
- Не могут деспавниться.
- У легендарных покемонов всегда фиксированные показатели мутации и пигментации.
- У них могут быть альтернативный арт.

## В открытом мире
- После генерации в областях генерации открытого мира покемоны перемещаются по области (в пассивном режиме), но могут выходить за её пределы при нападении или побеге. Максимальное время преследования вне зоны зависит от вида покемона и его характера. При превышении максимального времени покемон возвращается обратно в область.
- В зависимости от вида покемона, сгенерированного характера и дополнительных критериев (время суток, эффекты на персонаже, сопровождающий игрока покемон) покемоны могут попытаться напасть, игнорировать игрока или попытаться убежать. Радиус реагирования для нападения или побега зависит от вида и характера. В зависимости от вида у покемонов может быть «стадное поведение».
- В зависимости от времени суток и вида покемоны могут «спать» (радиус реагирования становится = 0, передвижение отключено, отображается отдельная анимация).

### Деспавн покемонов
- Только сгенерированные (зоной) покемоны могут деспавниться.
- Если игрок уходит дальше N метров от зоны генерации, покемон исчезает спустя определённое время.
- Если в зоне уже максимальное количество покемонов, новые не генерируются, пока кто-то не исчезнет.

## С игроком
- Можно выбрать до двух активных покемонов, которые будут путешествовать с тобой на карте. В зависимости от допустимости вида и выбранного положения они могут как следовать за игроком, так и размещаться на игроке (например: «сидеть на плече»).
- Присутствие некоторых путешествующих с игроком покемонов может создавать определённые эффекты (например: специфичная анимация или влияние на желание диких покемонов напасть или убежать).

## Косметические слоты (покемоны)
- Список возможных слотов: «голова», «хвост», «тело», «шея», «запястье», «представление» (альфа, злой, болеющий и другие).
- У каждого вида свой набор разблокированных слотов.
