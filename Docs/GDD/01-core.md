# 01 — Основы

> Нормализовано из `test.txt` (раздел «Основы»).

## Графика
- 3D.

## Мультиплеер
- Мир игры одиночный, не требует подключения к сети.
- Есть новости с сервера.
- Есть возможность к онлайн-подключению при регистрации на турниры, рейды или другие коллективные активности.
- Есть возможность торговать с другим игроком, если оба онлайн, по его ID.

## Камера
- Вид от третьего лица.

## Перемещение
- Выборочная схема управления: WASD + прыжок, **или** клик мышкой (без авто-совершения прыжков).
- В игре есть механизм телепортации:
  - с помощью навыка покемона (специальный флаг на покемоне или способности в пуле);
  - с помощью специальных объектов (например: корабли, поезда).
- Есть механика маунтов, ускоряющих передвижение (например: можно оседлать некоторых покемонов, скейт).

## Карта
- Есть полноценная карта мира (схематичная) с отображением игрока на ней.
- Миникарты нет.
